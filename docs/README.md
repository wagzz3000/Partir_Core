# Documentation

This folder contains all project documentation for Partir Core.

## Structure

### `architecture/`
System-level design documents, the provisional patent application, USPTO filing receipt, and visual architecture diagrams.

### `assets/`
Shared images, screenshots, and visual media referenced across documentation. Includes prototype photos and GUI screenshots.

### `design/`
Foundational design decisions, module specifications, and technology policies that shaped the project.

### `guides/`
Task-oriented documentation for operators and contributors. Covers running and deploying the prototype.

### `reference/`
Lookup material for APIs, CLI commands, and configuration options.

### `research/`
Background research, academic papers, and exploratory material that informed the design of Partir Core.
